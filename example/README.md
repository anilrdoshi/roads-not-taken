# Example explorer

`roads-not-taken-explorer.html` is the explorer for four example focal papers run through the tool: two versions of one study and two working papers. Each focal paper is shown under a label (Draft, Final, Modularity, Connectivity), without its title, authors or journal.

**Open it in your browser:** https://anilrdoshi.github.io/roads-not-taken/example/roads-not-taken-explorer.html

**Or download it and open it from disk.** Open [`roads-not-taken-explorer.html`](roads-not-taken-explorer.html) here on GitHub, choose *Download raw file* (the download arrow), then open the downloaded file in a browser: double-click it, or drag it onto a browser window. If it opens in another program, right-click it and choose *Open With* and your browser. It is one self-contained file of about 8 MB and needs no server, account or API key. GitHub's own file view shows only the raw file, not the explorer.

The file was written by `npm run export-explorer -- --anonymize` from the saved test runs of the four focal papers, which are not in this repository.
